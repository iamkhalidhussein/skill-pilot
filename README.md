# SKILL PILOT – Competency Assessment Platform

SKILL PILOT is a modern web platform designed to assess, track, and improve professional competencies.  
It enables individuals, teams, and organizations to evaluate skills, identify strengths, and discover areas for improvement through structured assessments.

## 🚀 Features

- **Skill-Based Assessments** – Evaluate competencies across different domains.
- **Customizable Tests** – Create and manage assessments tailored to specific needs.
- **Real-Time Results** – Instant feedback with detailed performance breakdowns.
- **User Dashboard** – Track progress and view past results.
- **Responsive Design** – Fully optimized for desktop, tablet, and mobile devices.
- **Secure Authentication** – Protects user data with modern authentication practices.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, React Router Dom, Redux  
- **Backend:** Node.js / Express.js
- **Database:** MongoDB
- **Authentication:** JWT & Firebase Auth  
- **Hosting:** Firebase Hosting
- **Email & SMS (otp):** Brevo 

## 📦 Installation & Setup

1. **Clone the repository**
   ```
   git clone https://github.com/iamkhalidhussein/skill-pilot.git
   ```
   ```
   cd skill-pilot
   ```

2. **Install Dependencies**
   ```
   pnpm install
   ```
   ```
   cd skill-pilot
   ```

3. **Run the development server**
   ```
   pnpm run dev
   ```
